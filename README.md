# Site Institucional — A+ Promotora

Landing page institucional e de captação de leads da A+ Promotora.

## Desenvolvimento local

```bash
docker build -t amais-promotora-site .
docker run --rm -p 8080:80 amais-promotora-site
```

- Site: http://localhost:8080
- Saúde: http://localhost:8080/healthz

## Fontes de conteúdo

- Materiais de marca enviados pelo proprietário
- Instagram oficial: https://www.instagram.com/amaispromotora/
- Facebook oficial: https://www.facebook.com/amaispromotora/
- Dados públicos verificáveis de endereço e contato

Crédito sujeito à análise, elegibilidade, margem e condições da instituição financeira.
